# 가이드 이미지 파일 규칙

가이드의 각 단계에 마우스를 올렸을 때 표시할 PNG 파일을 이 폴더에 둡니다.
파일이 없는 단계는 이미지 팝업을 표시하지 않습니다.

- 형식: PNG
- 파일명: `{topic-id}-{step-number:00}.png`
- 권장 크기: 800x500px 안팎
- 앱 표시 최대 크기: 440x300px (원본 비율 유지)
