# Mabinogi Overlay 0.0.4.1 패치 노트

기준 버전: `0.0.4-beta`

## 주요 변경사항

- 여러 프로필을 선택하고 적용할 수 있는 프로필 관리 화면을 추가했습니다.
- 프로필 이름 변경과 JSON 파일 불러오기·내보내기를 지원합니다.
- 프로필 삭제 시 복구 불가능 경고를 포함한 2단계 확인 절차를 추가했습니다.
- 활성 프로필을 앱 설정에 저장해 재실행 후에도 유지합니다.
- 설정창의 언어와 프로필 영역을 분리하고 렌더러 영역의 불필요한 여백을 줄였습니다.
- 앱 내부 가이드와 단계별 PNG 이미지 미리보기 기반을 추가했습니다.
- 메인 창과 보조 창의 상단 제목 정렬을 통일했습니다.

## 캡처 안정성

- 자동·수동 WGC 단일 캡처에서 프레임 객체가 다른 COM 스레드로 전달될 수 있던 문제를 수정했습니다.
- WGC 프레임 콜백에서 surface 복사를 시작하고, 동결된 이미지 결과만 UI에 전달하도록 변경했습니다.

## 호환성

- 기존 JSON 프로필은 그대로 사용할 수 있습니다.
- 기존 설정에 활성 프로필 정보가 없으면 `default` 또는 저장된 첫 프로필을 사용합니다.
- 가이드 PNG가 없는 경우에도 텍스트 가이드는 정상적으로 동작합니다.
