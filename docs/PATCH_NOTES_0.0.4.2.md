# Mabinogi Overlay 0.0.4.2 패치 노트

기준 버전: `0.0.4.1`

## 캡처 안정성

- 수동 WGC 선택기가 `디스플레이 1` 같은 모니터 항목을 반환해도 실행 중인 마비노기 `Client.exe` 창이 하나로 확인되면 해당 창의 HWND로 캡처 대상을 다시 생성합니다.
- 선택한 창 제목이 마비노기 창과 일치하지 않거나 여러 마비노기 클라이언트 때문에 대상을 확정할 수 없으면 캡처를 거부합니다.
- 수동 캡처에서 선택기의 모니터 항목을 그대로 사용하지 않으므로 의도치 않은 전체 화면 캡처를 방지합니다.
- WGC 테두리 권한 확인을 캡처 항목 생성보다 먼저 완료하여 `GraphicsCaptureItem`과 캡처 세션이 서로 다른 COM 스레드에서 연결되는 문제를 방지합니다.
- 자동·수동 단일 캡처 모두 권한 확인 후 같은 호출 흐름에서 캡처 항목과 세션을 생성합니다.
- 단일 캡처 완료 후 이벤트 구독과 WGC 세션을 생성한 UI 스레드에서 해제하여 `0x8001010E` COM 스레드 오류를 방지합니다.

## 호환성

- 기존 프로필과 설정 파일 형식은 변경하지 않았습니다.
- WGC를 지원하지 않는 환경의 기존 CPU 및 DXGI 캡처 동작에는 영향을 주지 않습니다.
