# Mabinogi Overlay 0.0.3-beta 패치 노트

기준 버전: `0.0.2-beta`

## 프로필과 저장

- 프로필 생성, 선택, 불러오기를 메인 화면의 전용 영역으로 이동했습니다.
- 후보, 섹션, 레이아웃, 오버레이 설정의 변경 사항을 자동 저장하도록 정리했습니다.
- 설정, 프로필, 세션 로그를 `%LocalAppData%\Mabinogi Overlay` 아래에 분리 저장하고 기존 portable 데이터를 첫 실행에 복사하도록 변경했습니다.
- GPU 오버레이의 상태 감시용 WGC CPU 프레임 변환을 2FPS로 제한하고, 버프 앵커 판정을 최소 영역에서 수행하도록 최적화했습니다.

## UI와 사용성

- 메인 화면 상단에 프로필과 오버레이 조작 영역을 분리했습니다.
- 후보 목록과 레이아웃을 비울 때 확인 절차를 추가했습니다.
- 후보를 삭제하면 연결된 오버레이 슬롯과 섹션에서도 함께 제거되도록 보강했습니다.
- 설정 창의 프로필 저장 경로 입력과 버튼 배치를 조정했습니다.
- 한국어/영어 문자열을 언어 파일로 분리해 런타임 언어 변경을 지원했습니다.

## 안정성

- 오버레이 시작과 프로필 자동 저장 처리의 예외 로그를 보강했습니다.
- 레이아웃 편집기 적용/닫기와 프로필 변경 시 저장 시점을 정리했습니다.

## 알려진 참고 사항

- 이 버전은 beta입니다. 캡처 방식, 화면 배율, UI 배치에 따라 추가 보정이 필요할 수 있습니다.
- WGC의 캡처 테두리 표시 여부는 Windows의 동작과 사용자 환경에 영향을 받습니다.
