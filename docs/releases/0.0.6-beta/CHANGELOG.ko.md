# Mabinogi Overlay 0.0.6-beta 변경사항

이 문서는 마지막 로컬 배포 패키지인 `0.0.4.3` 이후 `develop`에 통합된 변경사항을 정리합니다.

## 캡처와 렌더링

- 데스크톱 DXGI/GDI 캡처 대기를 UI 스레드 밖에서 처리해 캡처 대기 중 조작 지연을 줄였습니다.
- DXGI 장치·복제 세션·읽기용 텍스처와 CPU 합성 출력 버퍼를 재사용합니다.
- 중지·재시작 또는 캡처 대상 변경 이전의 비동기 결과가 새 실행에 적용되지 않도록 보완했습니다.
- WGC 크기 변경·대상 종료·실행 오류 처리를 보강하고, 5초 이상 오래된 WGC 프레임을 소비자에게 제공하지 않습니다.
- 모니터 감시 중 캡처·인식 오류를 표시하고 실행을 중지하며, OCR 사용 가능 여부를 시작 전에 확인합니다.
- 화면 밖 오버레이 위치를 실제 모니터 영역으로 복구하고 타이머 창에도 같은 위치를 적용합니다.

## 저장과 복구

- 원본 파일 복구에 실패해도 유효한 백업 데이터를 사용할 수 있도록 수정했습니다.
- 프로필 저장 실패를 표시하고 재시도하며, 쓰기 가능한 새 폴더를 선택해 복구할 수 있습니다.
- 저장 실패 상태에서 프로필 전환이나 앱 종료로 변경사항이 조용히 유실되지 않도록 보완했습니다.
- 에린 알람 저장 실패 시 변경사항을 유지하고 경고·주기적 재시도·종료 확인을 제공합니다.
- JSON 읽기 크기와 잘못된 컬렉션 항목을 검사하고, 투명도 0 설정을 보존합니다.
- 프로필 패키지와 오디오 파일의 형식·크기 등을 검사하고 잘못된 프로필 이름을 거부합니다.

## 사용성 및 알림

- 두 번째 실행은 별도 창을 만들지 않고 기존 창을 활성화합니다. 첫 창 준비 전 요청도 유지합니다.
- 설정 탭과 트레이 종료 동작, 트레이에서 오버레이 켜기·끄기를 정리했습니다.
- 레이아웃 다중 선택·그룹 이동·배율·화면 미리보기와 모니터 표시 조작을 개선했습니다.
- 함찌 다중 아이콘 버프 감지를 추가하고 기본 알림음을 교체했습니다.
- 제목 표시줄의 도구 설명과 접근성 이름을 한국어·영어로 제공합니다.
- OCR 진단 이미지 저장은 명시적으로 켜야 하며, 게임 화면 정보가 포함될 수 있음을 안내합니다.

## 검증과 배포

- Release 빌드 및 단위 테스트 158개를 통과했습니다. Windows CI를 포함합니다.
- Windows x64용 .NET 런타임 포함 portable 패키지이며, SingleFile·ReadyToRun 게시를 사용합니다.
- 실행 파일은 임시 자체 서명 인증서로 서명하고 타임스탬프를 추가합니다. 공인 인증서가 아니므로 Windows 신뢰 경고가 표시될 수 있습니다.
- 시험용 조작 도구, 합성 성능 측정 도구와 오류 주입 코드는 별도 `codex/test-tools` 브랜치에서 관리하며 배포에 포함하지 않습니다.
- 도움말 이미지는 다음 버전으로 미룹니다. 텍스트 도움말은 사용할 수 있습니다.

## 확인이 필요한 환경

실제 게임의 WGC/DXGI/GDI 캡처, GPU 전환, 창 크기 변경·최소화·재시작, 버프 인식·단축키, 다중 모니터와 DPI 조합의 수동 검증은 완료되지 않았습니다. 이 베타의 자동 검증 결과가 모든 실행 환경의 정상 동작을 보장하지는 않습니다.

업데이트 전 실행 중인 앱을 종료하고 ZIP 전체를 새 폴더에 압축 해제하세요. 기본 사용자 데이터는 `%LocalAppData%\Mabinogi Overlay`에 유지됩니다.
