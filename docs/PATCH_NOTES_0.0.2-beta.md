# Mabinogi Overlay 0.0.2-beta 패치 노트

기준 버전: `0.0.1-beta`

## 주요 변경

- 메인 화면과 보조 창에 다크 테마, 사용자 정의 타이틀 바, 로고, 한국어/영어 UI를 적용했습니다.
- 자동 캡처와 수동 WGC 캡처를 분리하고, `Client.exe` 우선 탐색을 추가했습니다.
- 실행 중 캡처 방식으로 WGC, DXGI Desktop Duplication, GDI BitBlt를 선택할 수 있게 했습니다.
- GPU/DXGI, CPU/Composited, CPU/WPF 렌더러와 렌더러 벤치마크를 추가했습니다.
- 퀵슬롯 인식을 ROI 기반 섹션 인식으로 바꾸고, 가로형/세로형 패턴을 자동 라우팅하도록 개선했습니다.
- 후보 슬롯의 수동 생성, 다중 선택, 이동, 삭제, 크기 변경, 섹션 관리, undo/redo를 보강했습니다.
- 레이아웃 편집기에서 그리드 스냅, 슬롯별 투명도/배율, 화면 미리보기 기반 위치 조정을 추가했습니다.
- portable 프로필, 설정, 세션 로그 저장을 정리했습니다.

## 알려진 참고 사항

- WGC는 Windows 환경에 따라 캡처 테두리가 보일 수 있습니다.
- DXGI와 GDI는 선택한 창이 위치한 모니터의 데스크톱 픽셀을 기반으로 하므로, 다른 창이 게임을 가리면 결과에 영향을 받을 수 있습니다.
- 자동 인식은 보조 기능이며 최종 후보와 레이아웃은 사용자가 보정하는 흐름을 전제로 합니다.
