# Mabinogi Overlay 0.0.5-beta 패치 노트

기준 버전: `0.0.4.3`

## 안정성

- 프로필 저장 실패 시 변경 내용을 유지하고 5초 간격으로 다시 저장을 시도합니다.
- 기존 폴더에 저장할 수 없을 때 설정에서 쓰기 가능한 새 프로필 폴더를 선택해 복구할 수 있습니다.
- 앱을 두 번 실행하면 두 번째 프로세스가 별도 창을 만들지 않고 기존 창을 활성화합니다.
- WGC 캡처 대상의 크기 변경과 창 종료를 감지하고 런타임 오류를 안전하게 처리합니다.

## 개인정보와 입력 안전성

- OCR 실패 화면 진단 이미지는 기본적으로 저장하지 않으며 설정에서 명시적으로 켜야 합니다.
- 진단 이미지 옵션에 게임 화면 정보가 포함될 수 있다는 안내를 추가했습니다.
- 사용자 오디오와 프로필 패키지의 형식, 크기, 압축 항목 수를 제한합니다.
- Windows 예약 이름과 잘못된 프로필 이름을 거부합니다.

## 화면과 문서

- 작은 화면과 고배율 환경에서 메인 화면을 스크롤할 수 있도록 최소 창 크기를 낮췄습니다.
- 앱 버전을 어셈블리 정보에서 표시해 버전 문자열 불일치를 방지합니다.
- GitHub 이슈 링크를 새 저장소 주소로 변경했습니다.
- 0.0.5-beta 수동 검증 매트릭스와 가이드 이미지 추가 방법을 보강했습니다.

## 검증 제한

WGC, DXGI, GDI 캡처와 실제 게임 창 오버레이 동작은 대상 Windows 환경에서 수동 검증해야 합니다.
